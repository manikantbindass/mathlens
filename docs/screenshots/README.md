# Screenshot provenance

These JPEG files are actual existing rendered captures from the initial MathLens visual alpha on 27 October 2026, copied unchanged from the local verification outputs. They are not generated mockups or captures of the latest deployment.

- `overview-desktop.jpg`: desktop overview, viewport capture.
- `overview-tablet.jpg`: tablet overview, full-page capture.
- `overview-mobile.jpg`: mobile overview, full-page capture.

They all show the overview route. Later authentication controls, version labels, and feature additions differ. Current release behavior is documented in the main README and release notes.

A current feature gallery should separately capture the overview, a computed model-lab result, an equation result, a gradient-descent trace, research, and a puzzle or lesson. Use sample data and public content; exclude account identifiers and private uploads. Record route, viewport, date, and whether the capture is from the hosted or local app. Do not present fabricated metrics or unconfigured authentication as working states.
