# Project explanation documents

- **MathLens-Project-Overview.pptx**: 20 editable PowerPoint slides.
- **MathLens-Project-Overview.pdf**: matching PDF pages.

The documents cover what MathLens is, what it does, how its APIs and mathematical algorithms work, privacy/authentication boundaries, setup/deployment, testing, distribution, and remaining gaps. They describe the 0.2.0-alpha.1 implementation as of 28 October 2026. Source citations appear in slide notes. All core content remains editable text.

The native release section explains the build gates and online-client architecture. The GitHub release assets and workflow receipts remain the source of truth for which platform builds actually passed. No document claims that a debug APK is a production store release or that the clients run offline.
