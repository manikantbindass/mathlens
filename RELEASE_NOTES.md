# MathLens web alpha

Local deterministic mathematical workbench. This is an early prerelease, not a completed production platform.

- **Web:** Node runtime source bundle in mathlens-web.tar.gz; requires Node 24–26. Extract and run `node server/index.mjs`.
- **Windows:** Native installer not built; use the Node web bundle locally.
- **Linux:** Native package not built; use the Node web bundle locally.
- **Android:** APK not built.
- **iOS:** Coming Soon.
- **Source:** Use the repository associated with this release.
- **Checksums:** SHA256SUMS.txt verifies the web archive.
- **Documentation:** README.md, DEPLOYMENT.md and DISTRIBUTION.md in the source repository.
- **Known issues:** Polynomial-only symbolic workbench; regression-only model lab; curated reference snapshots; no accounts, external inference, live research or native applications. See COMPLETION_REPORT.md.

This workflow creates a draft only. Review actual artifacts and tests before publishing. Never relabel this bundle as a native executable or APK.
